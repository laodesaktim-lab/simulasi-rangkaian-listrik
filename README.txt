# Simulasi Rangkaian Listrik

File:
- index.html
- style.css
- script.js

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Tidak membutuhkan server, framework, atau koneksi internet.

Fitur:
- Mode Seri, Paralel, dan Campuran.
- Baterai 1–24 V.
- Lampu/resistor 1–100 Ω.
- Menambah komponen dari panel kiri.
- Komponen dapat digeser.
- Panel pengaturan komponen.
- Perhitungan tegangan, hambatan total, dan arus.
- Perhitungan arus tiap cabang paralel.
- Tombol Jalankan/Berhenti/Reset/Hapus.
